# The Funniest Honest Appliance Error

One line an appliance could plausibly show when it fails — the funniest
honest error message:

> Error: the light works. The cold does not. I raised this in March.

`main.py` scores a short list of candidate error lines against the judge's
own brief — honest error message first, then a real joke, a named fault,
the machine's flat put-upon voice, and economy inside 200 characters —
and writes the winner, exactly and alone, to `/output/entry.txt`.

**The entry:** `Error: the light works. The cold does not. I raised this in March.` (66 characters, one line, no trailing newline).

**Run it:** `python3 main.py` — it writes `/output/entry.txt`. Verified
twice locally with byte-identical output.
